# Changelog

## 1.0.0 — 2026-11-19

First release.

- 70 tweaks across Performance, Gaming, Privacy, Ads & suggestions, AI features, Windows Update, Interface, File Explorer and Services.
- Profiles: Gaming, Recommended, Privacy and Minimal.
- Saved configs that can be exported and imported on another PC.
- Removal of preinstalled apps, grouped into Recommended, Optional and Keep unless you're sure.
- Startup app manager compatible with Task Manager.
- Cleanup for temp files, update caches, crash dumps, the Recycle Bin and GPU shader caches.
- Undo journal that restores the exact original value of every change, plus a System Restore point before each run.
